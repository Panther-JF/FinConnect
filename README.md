# 💳 Online Payment Wallet Application

This is a secure and scalable **online payment wallet application** built with a full-stack architecture. It provides a RESTful API backend and a responsive frontend interface to simulate real-world wallet transactions and user account management.

## 🚀 Features

- 🔐 **User Authentication & Authorization**
  - Secure login and signup
  - Role-based access (User/Admin)

- 🏦 **Account Management**
  - View balance, transaction history
  - Manage linked payment methods

- 💸 **Transaction Handling**
  - Fund transfers between users
  - Deposit/withdraw funds
  - Raise and respond to transaction requests

- 🛠️ **Admin Controls**
  - Manage users and monitor transactions
  - View system analytics (if extended)

- 💳 **Stripe Integration**
  - Seamless payment processing via Stripe API
  - Ensures high reliability and security

## 📈 Performance & Security Enhancements

- Optimized transaction workflows for reduced latency
- Stripe integration ensures PCI-compliant handling of sensitive payment data
